# Задание: Проектирование и настройка корпоративной сети малого предприятия

## Цель задания
Спроектировать и настроить сетевую инфраструктуру для малого предприятия в Cisco Packet Tracer, применив навыки:
- построения топологий;
- разделения сети на подсети;
- настройки маршрутизации;
- развёртывания DHCP и DNS;
- тестирования связности.

## Условия задачи
Компания (25 сотрудников) нуждается в сетевой инфраструктуре для двухэтажного офисного здания.

## Этапы выполнения

### 1. Разработка топологии сети (30–40 мин)

**Требуется:**
- Создать схему здания (2 этажа) в Packet Tracer.
- Разместить оборудование:
  - 2 маршрутизатора (по одному на этаж);
  - 2 коммутатора (по одному на этаж);
  - 1 сервер;
  - 12 ПК (5 на каждом этаже + переговорная + ресепшен).
- Обозначить кабельные соединения (медь/оптика).

**Результат:** готовая схема в Packet Tracer с размещённым оборудованием.

### 2. Разделение на подсети (20–30 мин)

**Требуется:**
- Разбить сеть на 4 подсети:
  1. Рабочие места (этаж 1);
  2. Рабочие места (этаж 2);
  3. Серверная зона;
  4. Гостиничная сеть (для посетителей).
- Использовать диапазон `192.168.0.0/24`.
- Рассчитать маски подсетей.

**Результат:** таблица подсетей:

| Подсеть | Сеть | Маска | Диапазон хостов | Шлюз |
|--------|------|------|-----------------|------|
| ... | ... | ... | ... | ... |

### 3. Настройка маршрутизации (20–25 мин)

**Требуется:**
- Настроить статическую маршрутизацию между подсетями.
- Обеспечить:
  - доступ всех ПК к серверу;
  - доступ гостей только к интернету (без доступа к внутренним ресурсам).
- Проверить связность командами `ping` и `traceroute`.

**Результат:** работоспособная маршрутизация, подтверждённая тестами.

### 4. Настройка сервисов (30–40 мин)

**DHCP:**
- Развернуть на сервере для каждой подсети рабочих мест.
- Задать исключения для серверов и шлюзов.

**DNS:**
- Настроить разрешение имён:
  - `server.company.local` → IP сервера;
  - `printer.floor1.company.local` → IP принтера (эмулировать).
- Проверить разрешение имён с ПК.

**Результат:** работающие DHCP и DNS‑сервисы.

### 5. Тестирование и документирование (20–30 мин)

**Тесты:**
- доступ ПК к интернету;
- доступ к серверу из разных подсетей;
- изоляция гостевой сети.

**Документация:**
- Скриншоты:
  - итоговой топологии;
  - таблиц маршрутизации;
  - результатов `ping`/`nslookup`.
- Отчёт (1 страница):
  - описание решения;
  - список проблем и их решений;
  - выводы по безопасности (изоляция сегментов).

## Критерии оценки

- Корректность топологии и размещения оборудования.
- Правильность расчёта подсетей и настройки маршрутизации.
- Работоспособность DHCP/DNS.
- Изоляция гостевой сети.
- Качество документации и тестов.

## Дополнительные вызовы (по желанию)

- Настроить VLAN для разделения трафика.
- Добавить резервный канал между маршрутизаторами.
- Эмулировать отказ линка и проверить отказоустойчивость.

## Формат сдачи

1. Файл Packet Tracer (`.pkt`).
2. Отчёт в PDF:
   - схема;
   - таблица подсетей;
   - скриншоты тестов.
3. Устный разбор решений (5 мин на группу).
